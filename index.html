      Security · Go · v0.2.0-dev
      
Nox

      
Two-stage network scanner written in Go: it first finds hosts and open ports fast, then identifies what is running on them. Output is JSON Lines for pipelines, and every scan is stored in SQLite so it can be compared with the previous one (nox diff).

      
    
        
  • Host discovery, a stateless SYN engine (Linux, root) with HMAC cookies and loss-based rate adaptation, and an unprivileged TCP connect scanner.
    • 
        
  • --deep: identifies SSH, HTTP(S)/TLS, SMTP, FTP, MySQL, Redis, SMB, PostgreSQL, RDP, MongoDB and more. Tested against real OpenSSH, nginx, Apache, MariaDB, Redis and Samba.
    • 
        
  • UDP scanning, -T 0–5 timing profiles and a plugin system (4 built-in read-only plugins, plus your own in any language) with JSON rules.
    • 
        
  • Secure by design: plugins run without a shell, with a minimal environment and time and output limits; banners are filtered to printable ASCII.
    • 
      

      
  • Go
  • Raw sockets
  • SQLite
  • JSONL
  • Plugins

      
Independent project, at an early stage and tested on loopback and local software. For use on authorized systems only.
